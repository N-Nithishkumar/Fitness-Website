# 🏋️ MAX Fitness 2.0

MAX Fitness 2.0 is a modern, personalized digital fitness coach built with React and Vite. It goes beyond a simple gym website by adapting its entire interface and content based on your specific fitness goal.

## 🚀 Features
- **Dynamic Onboarding:** Start your fitness journey by selecting your core goal (Bulking, Weight Loss, Cardio, Strength, or General Fitness).
- **Personalized Workouts:** Depending on your goal, the app generates a specific multi-exercise workout circuit. The UI includes a sequential progression system—complete all sets of an exercise to unlock the next one!
- **Tailored Nutrition Plans:** Features comprehensive meal plans with real, goal-specific foods (e.g., Caloric surplus meals for Bulking, high-volume/low-calorie for Weight Loss).
- **Supplements Toggle:** Dynamically switch your Pre and Post-Workout meals between Natural foods and Supplements.
- **XP & Level System:** Earn XP by completing workout sets and drinking water. Track your progress on your personalized Dashboard.
- **Responsive Design:** A beautiful glassmorphism interface that looks like a native mobile app on your phone, complete with a sticky Bottom Navigation bar.

## 🛠️ Technology Stack
- **Frontend:** React 18, Vite, React Router DOM, Lucide Icons
- **Styling:** Vanilla CSS (Glassmorphism, Modern gradients)
- **State Management:** React Context API

## 🏃‍♂️ Running Locally
1. Clone the repository.
2. Navigate to the `client` directory: `cd client`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`

Enjoy your personalized fitness journey!
